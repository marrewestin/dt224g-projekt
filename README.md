# Projektuppgift
## I kursen Introduktion till webbutveckling med HTML, CSS och JavaScript, DT224G - HT2026
### Av Maria Westin
Webbplats till det fiktiva bageriet BAKA. Webbplatsen presenterar företaget och dess sortiment samt kontaktuppgif-ter. Den består av fyra HTML-sidor i en responsiv design som anpassar innehållet till skärmstorleken.
CSS har använts för att styra webbplatsens utseende och JavaScript har använts för att skapa en hamburgermeny, läsa in artiklar från en extern json-fil, samt för att validera kontaktformuläret. 
### Webbplatsen är publicerad på: https://projekt-baka.netlify.app
